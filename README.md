# ziovpontvrs

## Сборка

```bash
cmake -B build -DCMAKE_TOOLCHAIN_FILE=cmake/toolchain-mingw64.cmake
cmake --build build
```

Результат: `build/ziovpontvrs.exe` (GUI) и `build/ziovpontvrs_svc.exe` (сервис).

## Установка сервиса

Из командной строки с правами администратора:

```cmd
ziovpontvrs_svc.exe install
```

Сервис зарегистрируется с автоматическим запуском.

Для удаления:

```cmd
ziovpontvrs_svc.exe uninstall
```

## Возможности

### Графическое приложение (`ziovpontvrs.exe`)

- Иконка в системном трее создаётся при запуске и пересоздаётся при перезагрузке панели задач
- Клик левой кнопкой мыши по иконке — открытие главного окна
- Клик правой кнопкой мыши — контекстное меню (Открыть / Выход)
- Закрытие окна скрывает его, приложение продолжает работать в трее
- Меню Файл → Выход завершает приложение
- Запускается только в одном экземпляре (именованный мьютекс)
- При запуске проверяет состояние сервиса и запускает его, если он остановлен
- Поддерживает флаг `--silent` / `/silent` для запуска без отображения окна

### Сервис (`ziovpontvrs_svc.exe`)

- Регистрируется как служба Windows с автоматическим запуском
- При старте запускает GUI-приложение во всех активных терминальных сессиях (скрытно)
- Отслеживает вход пользователей (WTS_SESSION_LOGON) и автоматически запускает GUI в новых сессиях
