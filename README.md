# ziovpontvrs

## Сборка

Требуется MinGW-w64 и утилита `widl` (генератор RPC-стабов, входит в пакет
`mingw-w64-tools`).

```bash
cmake -B build -DCMAKE_TOOLCHAIN_FILE=cmake/toolchain-mingw64.cmake
cmake --build build
```

Результат: `build/ziovpontvrs.exe` (GUI) и `build/ziovpontvrs_svc.exe` (сервис).

## Установка сервиса

Из командной строки с правами администратора:

```cmd
ziovpontvrs_svc.exe install
```

Сервис зарегистрируется с автоматическим запуском.

Для удаления:

```cmd
ziovpontvrs_svc.exe uninstall
```

## Архитектура

### Межпроцессное взаимодействие

Сервис и GUI общаются через **Windows RPC** с транспортом **ALPC**
(`ncalrpc`). IDL-файл: `src/rpc_iface.idl`, общие настройки транспорта —
`src/rpc_common.h`. Интерфейс состоит из одного метода `RpcShutdown()`,
которым клиент останавливает сервис.

### Графическое приложение (`ziovpontvrs.exe`)

- При старте проверяет состояние сервиса. Если тот остановлен — запускает
  его и ждёт состояния `Running`, после чего завершает работу.
- Проверяет родительский процесс: если это не `ziovpontvrs_svc.exe`,
  приложение немедленно завершается. Таким образом GUI запускается только
  сервисом.
- Главное окно при старте скрыто.
- Пункт **Файл → Выход** и пункт **Выход** в контекстном меню иконки трея
  вызывают RPC-метод `RpcShutdown`, что останавливает сервис (который, в
  свою очередь, завершит все запущенные GUI-приложения).
- Клик левой кнопкой по иконке трея открывает главное окно, правой —
  контекстное меню (Открыть / Выход).
- Закрытие окна (крестик) скрывает его; приложение продолжает работать в
  трее.

### Сервис (`ziovpontvrs_svc.exe`)

- Регистрируется как служба Windows с автоматическим запуском.
- При старте запускает `ziovpontvrs.exe --silent` во всех активных
  терминальных сессиях (кроме сессии 0) от имени владельца сессии.
- Отслеживает события `WTS_SESSION_LOGON` и запускает GUI в новых сессиях.
- **Не принимает** управляющие сигналы `SERVICE_CONTROL_STOP` и
  `SERVICE_CONTROL_SHUTDOWN`. Остановка возможна только через RPC-метод
  `RpcShutdown`.
- Запускает RPC-сервер на ALPC-эндпоинте `ZiovpontvrsRpcEndpoint` и
  блокируется в `RpcServerListen` до тех пор, пока клиент не вызовет
  `RpcShutdown`.
- При остановке завершает все запущенные им GUI-приложения через
  `TerminateProcess`.
